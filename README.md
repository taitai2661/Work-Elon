# 働けイーロン

スマホ・PC対応の1ファイルブラウザゲームです。降ってくる仕事カードを正しい会社の箱へドラッグし、「睡眠」だけはタップして却下してください。30秒間のスコアを競います。

## 遊び方

1. 「労働開始」を押します。
2. 仕事カードを正しい会社の箱へドラッグします。
3. 「睡眠」はタップして却下します。
4. 30秒間でできるだけ高いスコアを目指します。

## ローカルで実行

`index.html` をブラウザで直接開くか、次のような静的Webサーバーで配信してください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで <http://localhost:8000> を開きます。

## 技術構成

ビルドツールや外部ライブラリを使わない、HTML・CSS・JavaScriptだけの構成です。そのため、GitHub Pages、Cloudflare Pages、Netlifyなどの静的ホスティングにそのまま配置できます。
